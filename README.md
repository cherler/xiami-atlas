# 虾米看AI · AI 能力核验地图

> 谁能做什么、什么时候长出来的、拿什么跑 —— **每一格都挂着官方原话和核验日，没原话的格子就空着。**

线上：**<https://xiamimate.com/atlas>** · 平台首页：<https://xiamimate.com>

满屏都写着「最强」，没人告诉你哪句是官方写过的。这个项目做的事很窄：把模型 × 能力
摆成一张表，**每一个「支持」都必须能点开看到厂商自己写的那句话，和我们核验它的日期**。
核不出来的就留空 —— 不猜、不推断、不拿第三方评测代替厂商声明。

当前数据：**133 个模型 · 1012 格能力 · 677 格挂着官方原话 · 429 个登记在册的信息源**

## 它长什么样

- **能力矩阵** —— 模型 × 能力，九卷各一张：视频 / 图像 / 文本 / 声音 / 3D /
  数字人 / 具身智能 / 世界模型 / 科学
- **版本谱系** —— 厂商自己发布的版本与日期，画的是「这一代新增了什么」；
  只有版本号、没有新增内容的节点不收
- **专项页** —— AI 视频制作、AI 游戏制作：开源项目、工作流、教程。
  星速与停更月数按公式实时算，对不上就报错，不是手写的数字

## 它凭什么可信

这个仓最值钱的不是页面，是**让它自己发现自己错了**的那几支脚本：

| 脚本 | 它回答的问题 |
|---|---|
| `scripts/watch.mjs` | 429 个源里到期的那些，今天变了吗？（纯程序，不调模型） |
| `scripts/requote.mjs` | 一格引文里的原句，在它署名的那份快照里还在不在？ |
| `scripts/version-sentry.mjs` | **快照里已经出现、我们却还没写回的版本号** —— 抓到了不等于写回了 |
| `scripts/fresh.mjs` | 开源项目的星数、README 口径、外链，今天还成立吗？ |
| `scripts/validate.mjs` | 一百多条数据规则；`test-rules.mjs` 再验一遍「说数据不对的那些规则，自己会不会说话」 |

这几支的开头注释写的都是**它为什么存在**，通常是某次翻车。比如版本哨兵那段记着：
新版模型早就躺在我们自己的快照里，定时任务每天照跑、退出码 0，
只是没有任何一步会说「这条要写回」。

## 跑起来

```bash
npm install
npm run validate      # 数据规则自检 —— 数据坏了就不该有产物
npm run dev           # http://localhost:3400/atlas
```

采集是另一条线，跑在别处：

```bash
node scripts/watch.mjs --due          # 抓到期的源 → data/snapshots/
node scripts/requote.mjs --report     # 引文回查
node scripts/version-sentry.mjs       # 版本哨兵（--at <git ref> 可拿历史快照自检）
node scripts/todo.mjs                 # 汇总成一张「该你看了」
```

## 数据长什么样

- `data/atlas.json` —— 唯一的真源。模型、能力、支持关系、版本谱系、来源登记，
  每条事实带 `src` / `as_of` / `quote`
- `data/sources.json` —— 429 个信息源，各自的抓取周期与权威等级
- `data/snapshots/` —— 各源的正文快照。**引文回查与版本哨兵都靠它工作**
- `data/ontology.md` —— 收录规则：「什么算一个模型」「什么算一项能力」在这里定死

## 三条锁定的约束

违反其中任何一条的方案都应当被否决：

1. **关系图的枢纽是能力，不是公司。** 公司是模型节点上的徽标，不占节点
2. **每条事实必须带来源、日期，和「机器录入 / 人工核验」标记。** 宁可不精准，不许没出处
3. **机器不碰 `atlas.json`。** 抓取、回查、哨兵只写报告 ——
   「世界变了」和「我们认定它变了」是两件事，后者要走人审

## 不做什么

不做评测、不做排行榜、不做「最好的 AI 工具推荐」。能力核验回答的是
**它声称能做什么、谁写的、什么时候写的**；好不好用是另一回事，那得你自己试。
