## 一句话

> **这是一张能核验的 AI 能力地图 —— 每一格「这个模型能不能做这件事」，
> 背后都挂着厂商官方原文、来源链接和核验日期。**

不是榜单，不是评测，不是导航站。

---

## 最容易讲偏的三件事

### 一、主角不是 ✅，是 ⬜

593 个核心格子里 ⬜ 占 **36%**。一般人会把它当成「数据不全，别提」—— **恰恰相反。**

三色是严格分开的：

| 记号 | 含义 | 硬约束 |
|---|---|---|
| ✅ | 能做 | **必须带官方原文，340 格无一例外** |
| ❌ | 不能做 | 官方**明确说了**不能 |
| ⬜ | 不知道 | **我们查了，公开渠道没说** |

**「官方没说」和「不支持」是两件完全不同的事**，全网几乎没有第二个地方替读者分开。

> 这张表最诚实的部分，是它承认自己不知道什么。

### 二、不打分、不排名、不推荐

- 效果**只转述并标明是谁说的**；
- 价格**只指路不转述**；
- 工具箱每条都必须写负面结论 —— 校验规则卡着，**没有 caveat 进不了库**。

### 三、它会自己发现自己错了

97 条校验规则卡在提交与构建之前。**红了就没有产物。**

## 怎么重新取数

数据每天在动，做片子当天**重取一遍**，别用上面这张表的旧值。

```bash
cd xiamimate-ai-atlas
node -e "
const a=require('./data/atlas.json');
const core=m=>(m.tier??'core')==='core';
const ids=new Set(a.models.filter(core).map(m=>m.id));
const cells=a.support.filter(s=>ids.has(s.m));
const st={}; for(const s of cells) st[s.state]=(st[s.state]||0)+1;
console.log('卷', a.domains.length, '| 产品线', a.models.length, '（核心', ids.size, '）');
console.log('能力', a.capabilities.length, '| 核心格子', cells.length, JSON.stringify(st));
console.log('⬜ 占比', (st.unknown/cells.length*100).toFixed(0)+'%');
console.log('✅ 无来源的', cells.filter(s=>s.state==='yes'&&!s.src).length, '（必须是 0）');
console.log('发布', a.versions.length, '| 来源', Object.keys(a.sources).length, '| 应用', a.applications.length);
"
find out -name '*.html' | wc -l      # 静态页
```

### 三处口径要注意

脚本跑出来的数和上表可能不一致，**以负责人口径为准**，但要知道差在哪：

| 项 | 上表（负责人口径） | 脚本直取 | 差在哪 |
|---|---|---|---|
| 官方来源 | 267 | `tier==='official'` 数出 270 | 分级口径 |
| 静态页 | 554 | `find out -name '*.html'` 数出 552 | 是否含重定向/占位页 |
| 校验规则 | 97 | `validate.mjs` 里 73 个 R 编号 | 规则条目 ≠ R 编号（一个编号可含多条） |
| 谱系起点 | 2023 年 | `versions` 最早 2022-08-20 | 页面展示起点 vs 数据最早一条 |

**片子里按上表说。** 这四处不要临时改口径 —— 一支片里同一个数只能有一个说法。

## 给做片子的人的三条硬约束

来自 `北极星.md` 与 `用户拍板清单.md`，违反就是白做：

1. **验收标准是「靠，我终于搞懂 X 和 Y 是什么关系了」，不是「这个网站好酷」。**
   凡是让人「看懂一张表」但没让人「搞懂一层关系」的，都没达标。
2. **每一镜要有观点，不能只有主题。** 反例：「AI 视频能力演进」。
   正例：「AI 视频这两年最大的进步，其实不是画质，而是控制能力。」
3. **两道题都要过**：去掉它，用户会少理解什么（理解测试）；
   去掉它，还有人会把它转出去吗（分发测试）。**一张没人转的清晰图，价值是零。**
