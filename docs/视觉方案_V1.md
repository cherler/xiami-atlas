# 视觉方案 V1 —— 每页一张主图

> 2026-08-09 定。上一版前端的病不是难看，是**十三页共用一个模板**：标题 + 灰色说明 + 圆角卡片 + 列表。
> 本文规定：**每一页必须有一张主图，它是数据的形状。** 没有主图的页不许上线。
>
> 本文只管「长什么样」。数据规矩在 `AI_VIDEO_ATLAS_HANDOFF_V1.md`，页面职责在 `前端落地方案_V1.md`。

## 一、命题

| | |
|---|---|
| 这是什么 | 一份对 AI 能力**逐格核验**的图谱。第一卷 AI 视频，往后文本、具身、世界模型 |

## 二、三条原则（每条都能被证伪）

**1. 每页一个视觉主体，主体是数据的形状。**
判据：把这一页所有句子删光再截图 —— 还剩一个有形状的东西算过，剩一堆卡片和横线算不过。

**2. ⬜ 是主角，不是缺陷。**
别人的对比表全是勾，因为靠猜。我们的空白是真事实。
判据：⬜ 必须是页面上视觉权重最高的三个元素之一。
**这条我在三版设计稿里连续违反了三次** —— 嘴上说主角，手上做成最淡的灰点。定成硬判据就是为了防它再犯。

**3. 酷 = 密度 × 精度，不是特效。**
判据：首屏可核验的具体事实（模型名／日期／数字／格子）**≥ 100 个**。
旧首页横条图 = 18 个。规格书首屏 = 147 个。差八倍，这就是"一眼看不懂"的真实原因，跟审美无关。

## 三、Token

```
色   paper   #FBFBF9   纸
     ink     #0B0B0C   墨
     blue    #0A3CE0   ★ 唯一强调色 = 「有出处」
     hatch   #E4E5E0   未公开：整格 45° 斜线纹理
     rule    #C9CBC6   细分隔线
     soft    #6E7069   次要文字
```

**强调色给「有出处」，不给「支持」。** 这是立场：我们不评判谁强，只记录谁说过。
所以没有绿=好、红=坏那套 SaaS 语义色。「❌ 厂商明确说不支持」用**黑色叉**，它是一条事实，不是一个差评。

```
字   标题   Helvetica Neue Condensed Black / PingFang SC Semibold
     数据   Menlo（全部数字、日期、代号、编号，tabular-nums）
     正文   PingFang SC
     —— 全部为 macOS 系统内置，不加载任何网络字体
```

```
版   零圆角 · 零阴影 · 零卡片
     分区只用两种线：2.5px 粗线（区块）/ 0.5px 细线（行）
     表格行高固定 36px
```

**明令禁止**：`border-radius`、`box-shadow`、`border + background` 拼出来的卡片、hover 变色、
成段的灰色说明文字、emoji 当图标。这六样是上一版"什么都不是"的构成材料。

## 四、每页主图清单

共 13 条路由。**★ 标记的五页共用同一套真值表语言** —— 统一，但每页问的问题不同。

| 页 | 它问什么 | 主图 | signature |
|---|---|---|---|
| ★ `/` | 谁能做什么 | **9×10 真值表**，行头带支持数横条与起始年月 | **脚注系统**：每个 ✅ 带上标编号，页脚是那句厂商原文 |
| `/tree` | 谁在什么时候长出了什么 | **系统发生树**：67 次发布纵向时间轴，开源／闭源双主干 | 开源实心 · 闭源空心 |
| `/map` | 谁是谁家的 | **桑基图** 公司 → 团队 → 产品线，带宽＝已核验能力数 | 15 家公司一次看全 |
| ★ `/where` | 去哪用、多少钱 | **平台×模型真值表**，格子＝上架／旧版／停服 | 点格子出八字段 |
| `/caveats` | 能力对了为什么用不上 | **断裂图**：左「表说支持」→ 右「实际用不上」，线断在哪一环 | 五种断裂各一形态 |
| `/models` | 全部有哪些 | **点阵**：18 个模型按发布日期 × 层级（主表／Extended／停服） | 停服的不删，降层显示 |
| `/skill/[id]` | 这件事怎么做 | **输入→输出框图**（§10 原样：人物图＋驱动视频 → 结果视频） | 「已知限制」与做法同等大小 |
| ★ `/compare/[a]-vs-[b]` | 这两个选哪个 | **双列对照真值表**，中列标共有／独有 | 价格不换算，原样并排 |
| `/capability/[id]` | 这项能力谁实现了 | **单项时间轴**：9 个模型各自何时实现 | 最早可证日期带原文 |
| ★ `/model/[id]` | 这个模型的全貌 | **单页规格卡**：一列真值表＋版本谱系小图 | Rev. 号与核验日期 |
| `/changes` | 变了什么、意味着什么 | **Before／After 数值条** ＋ 时间轴 | So What 与 Change 同权重 |
| ★ `/toolkit` | 想查 X 该去哪 | **任务×站点矩阵**，格子＝在这儿查不查得到 | 负面结论用叉，不用文字 |
| `/method` | 你们凭什么 | **图例块本身** ＋ 来源分级 S/A/B/C 层级图 | **全站唯一允许成段文字的地方** |

`/evolution` 不建。它的职责（§9.2 能力演进）已被 `/tree` 与首页行头的横条吸收。
**「一个判断＋一张图＋证据」（§18）改挂在 `/tree`**，判断句取自数据，不预设。
