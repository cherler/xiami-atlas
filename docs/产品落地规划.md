> 取代 `前端落地方案_V1.md` 里的实施顺序那一节（第六节）。
> 那份文档的**页面规格仍然有效**，变的是排序 —— 理由见第三节。
>
> 排序改过两次，记下来免得再摇摆：
> 第一版把「拆页骨架」排第一；负责人说「不够酷就没人看」，我就把演化树整个提到第一 ——
> **那是把一句话当成了全部排序**。演化树是屋顶：没有数据、没有落脚页、没有动线，
> 先画树等于把唯一一次分发机会引到一个死站。
> 最终顺序由**依赖**决定，不由「哪件事更重要」决定。
> 拍板过的约束见 `用户拍板清单.md`，本文不重复。

## 一、这个产品到底卖什么

一句话：**同一件事，九家谁能做、做到什么程度、在哪能用上、多少钱 —— 每一格都能点开看厂商官方原文。**

拿「别处能不能拼出来」这把尺子量每一类内容：

| 内容 | 别处有没有 | 我们的价值 |
|---|---|---|
| 单个模型能做什么 | 官网就有 | **没有** |
| 谁画质更好 | Artificial Analysis 就有 | **没有** |
| 横向：同一件事九家谁能谁不能 + 官方出处 | 得自己翻九个文档站 | 有 |
| 纵向：一个模型两年每代加了什么、谁掉队 | 得自己翻 changelog | 有 |
| **能力对 ≠ 你用得上** | 几乎没人拼 | **最值钱** |

第三条最值钱，因为它**反直觉、而且能防止真金白银的损失**：

- Sora 上游 2026-09-24 停服，**Replicate 和 APIYI 还在卖**
- Replicate 上的「Hailuo」是 2.3，不是当前的 H3；LTX 是初代不是 2.3
- 同一个万相，百炼 ¥0.6/秒、Replicate $0.25/秒，而且 Replicate 卖的是 2.1
- MiniMax 视频资源包**不支持它自己的主力 H3**

**这才是产品，前两条是内容农场。**

## 三、排序原则

**先问「靠什么把人引来」，再问「引来之后靠什么留住」。** 但这两句不是排序，是目标。
真正决定顺序的是**依赖**：

> **演化树是屋顶，不是地基。** 它要能兑现「一张图就够分发」，先得有三样东西：
> ① 足够的数据（19 → 60 条）② 一个能落脚的页 ③ 点进来之后的下一步。
> 三样都没有的时候先画树，等于**把唯一一次分发机会引到一个死站**。

所以顺序是：**动线 → 结构 → 数据 → 树 → 留住 → 复访**。

树的重要性没降，位置变了 —— 它排在能撑住它的东西后面。

## 三之一、用户动线（此前完全空白）

我写过 12 个页面的规格，**但从没定过「人到站之后怎么走」**。
没有动线，拆页只是把一堆页面摆开。三条主动线，页面的必要性由它们决定：

### 动线 A：我要做一件事，用谁？（**最高频，也最该被优化**）

```
入口（搜索引擎 / 分享图 / 朋友转发）
  → 首页任务入口「你想做什么」
  → 候选模型清单（带价格、平台、大陆可达性）
  → /compare 两个选一个
  → /where 去哪用、多少钱
  → 完成
```

必需页：首页 · /compare · /where · /model

### 动线 B：这东西现在到什么程度了？（**分享图带来的人走这条**）

```
入口（演化树分享图）
  → /tree 完整演化树
  → 点一个节点 → /model 单模型全貌
  → 「它能做什么」→ 能力矩阵
  → 「我能用上吗」→ /where
```

必需页：/tree · /model · /capability · /where

### 动线 C：我在追踪这个领域（**复访靠它**）

```
入口（订阅 / 周报 / 直接来）
  → /changes 变了什么 + 意味着什么
  → 订阅某个模型或某项能力
```

必需页：/changes · 订阅

**三条动线的交汇点都是 `/where`** —— 「能力对 ≠ 你用得上」既是最值钱的内容，
也是动线上的枢纽。它排在树前面。

## 五、每个任务通用的交付条件

任何任务都要同时满足，不满足就不算完：

1. **数据有来源** —— 每条事实带 src + 逐字原文，校验通过
2. **前端不放旁白** —— 口径去 `/method`，原地只留角标
3. **删掉正文仍看得懂** —— §7.1 的验收
4. **控制台无报错** —— `scripts/verify.mjs` 通过（含 hydration 一类的隐性错）
5. **移动端可用** —— 不是桌面端缩小
6. **改了数据就重出分享图** —— `scripts/package.sh` 已串好

## 六、明确不做的

- **不上线**，直到批次 A~D 交付且负责人点头
- **不同时开两个方向** —— 会击穿每周 3 小时
- **不做终端用户分布** —— 没有厂商公开，画出来一定是编的
- **不做 3D 地球** —— 等两个方向上线 + 公司数 ≳40
- **不镜像别人的 demo 视频**（§45）
- **不要廉价的酷** —— 赛博朋克 / 霓虹 / 粒子 / 乱漂的卡片，那是拿可信度去换
